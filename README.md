# Ranto Portfolio

Create a premium, modern, responsive Personal Portfolio Website for me.

Theme:
Minimal, elegant, professional, futuristic, Apple + Microsoft + Vercel inspired design with smooth animations, glassmorphism, subtle gradients, rounded corners, soft shadows and excellent spacing. The website must look like a premium software engineer portfolio that recruiters would expect from a top developer.

Do NOT use any profile picture or stock images. Instead, create a beautiful circular avatar using only my initials "TR" with a blue gradient background and subtle animated glow. The initials should be generated from the first and last name so I can easily change them later.

IMPORTANT:
Create one simple configuration object at the top of the project that allows me to change my personal information without editing multiple files.
