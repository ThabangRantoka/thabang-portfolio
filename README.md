# Thabang Rantoka — Upgraded Portfolio

A responsive, static portfolio for GitHub Pages. Includes `index.html`, `styles.css`, `script.js`, and the existing `profile.png`.

## Publish to GitHub Pages

1. Open your `ThabangRantoka/thabang-portfolio` repository on GitHub.
2. Back up your existing repository or create a new branch.
3. Upload **the contents of this folder** to the repository root (not the enclosing folder), replacing the old compiled website files.
4. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)` if not already configured.
5. Wait for deployment, then visit https://thabangrantoka.github.io/thabang-portfolio/.
